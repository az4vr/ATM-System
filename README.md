# ATM-System
About
An ATM Management System that allows users to securely log in using their account credentials and perform basic banking operations such as quick withdrawal, normal withdrawal, cash deposit, balance inquiry, and logout.

A simple ATM Management System that allows users to log in using their credentials and perform basic banking operations.

# Features
Login with Account Number and PIN
Quick Withdrawal
Normal Withdrawal
Cash Deposit
Check Balance
Logout

# Technologies Used
Programming Language: C++
